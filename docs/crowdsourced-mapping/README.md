# Crowdsourced Mapping & POI Refinement Subsystem

## Project: IndoorPulse – Indoor Navigation System

**Course:** UCS503 – Software Engineering  
**Contributor:** Pooja  
**Module:** Crowdsourced Mapping & POI Refinement

## 1. Overview

The Crowdsourced Mapping and POI Refinement subsystem aims to improve indoor navigation maps by enabling users to contribute new mapping information and refine existing map data.

## 2. Subsystem Responsibilities

### Record Unmapped Pathway
Allows users to contribute information about previously unmapped indoor pathways.

### Tag and Register Shop POI
Supports the registration of shops and other Points of Interest within an indoor environment.

### Report Dynamic Obstacle
Covers the reporting of temporary obstacles that may affect indoor navigation.

### Data Synchronization
Covers the synchronization of contributed mapping information with the backend server and database.

## 3. Objectives

- Improve indoor map coverage.
- Maintain accurate Point of Interest information.
- Support user-driven map refinement.
- Improve the reliability of indoor navigation.
- Maintain consistent mapping data.
